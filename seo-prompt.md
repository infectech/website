# Website SEO Prompt — Infectech

Audit, optimize, and implement a complete **technical, on-page, and content SEO strategy** for the Infectech website.

**Website:** Infectech  
**Website URL:** https://infec.tech/  
**Brand:** Infectech  
**Industry:** Software development, web development, AI solutions, digital products, and business technology solutions.

## 1. Primary Goal

Improve Infectech's visibility on search engines and ensure that the website is properly optimized for potential clients searching for professional technology and software solutions.

The SEO strategy should focus on:

- Software development services
- Web design and web development
- Custom business software
- AI-powered solutions
- SaaS and digital product development
- E-commerce technology solutions
- Technology solutions for businesses

The website should feel professional and trustworthy while targeting both **local clients in Bangladesh** and **international clients**.

---

# 2. SEO Audit

First, perform a complete audit of the existing website and identify:

### Technical SEO
- Missing or duplicate page titles
- Missing or weak meta descriptions
- Improper heading hierarchy
- Missing canonical URLs
- Broken internal or external links
- Missing image alt text
- Large or unoptimized images
- JavaScript rendering issues affecting search engines
- Slow-loading pages
- Mobile responsiveness issues
- Missing sitemap.xml
- Missing robots.txt
- Incorrect indexing settings

Do not make SEO changes blindly. Review the existing website structure and preserve the current design, branding, and user experience wherever possible.

---

# 3. Page Titles and Meta Descriptions

Create unique, keyword-focused metadata for every important page.

The homepage title should clearly communicate what Infectech does.

Example direction:

**Title:**  
Infectech | Web Development, Software & AI Solutions

**Meta Description:**  
Infectech builds modern websites, custom software, AI-powered solutions, and digital products that help businesses grow and operate smarter.

Avoid keyword stuffing. Titles and descriptions should sound natural, professional, and appealing to potential clients.

Each service, product, portfolio, and contact page should have its own unique SEO metadata.

# 5. Homepage SEO Structure

Ensure the homepage has a clear semantic structure.

There should be only **one primary H1** that clearly explains the company's core value proposition.

Example direction:

**H1:**  
Building Digital Solutions for Modern Businesses

Supporting content should clearly explain what Infectech offers, who the company helps, and why clients should choose its solutions.

Use descriptive H2 sections such as:

- Our Services
- Software & Digital Solutions
- Products We Build
- Why Choose Infectech
- Our Work
- Let's Build Something Together

The content should provide enough meaningful information for search engines to understand the business without making the homepage feel overcrowded.

---

# 8. Structured Data

Implement appropriate Schema.org structured data in JSON-LD format.

Consider:

### Organization Schema
Include:

- Infectech name
- Website URL
- Logo
- Company description
- Social media profiles

### WebSite Schema
Help search engines understand the main website.

### Service Schema
Use for major services where appropriate.

### SoftwareApplication or Product Schema
Use for software products when the page contains enough relevant product information.

### Breadcrumb Schema
Use if the website has a multi-level page structure.

Ensure all structured data is valid and does not contain misleading information.

---

# 9. Image SEO

Optimize all website images.

For every meaningful image:

- Add descriptive alt text
- Use relevant filenames where possible
- Compress images without significantly reducing quality
- Use modern formats such as WebP or AVIF where supported
- Implement responsive image sizing
- Avoid unnecessarily large images

Do not use keyword-stuffed alt text.

Decorative images should use appropriate empty alt attributes where necessary.

---

# 10. Technical SEO Requirements

Implement the following technical SEO essentials:

### robots.txt
Create and configure a proper robots.txt file.

### sitemap.xml
Generate a dynamic or static sitemap containing all important indexable pages.

### Canonical URLs
Add canonical tags to prevent duplicate content issues.

### HTTPS
Ensure the website is fully served through HTTPS.

### Mobile Optimization
The entire website must work properly across mobile, tablet, and desktop devices.

### Performance
Optimize for strong Core Web Vitals:

- Fast Largest Contentful Paint
- Low Cumulative Layout Shift
- Responsive interaction performance

Reduce unnecessary JavaScript, optimize fonts, lazy-load non-critical images, and optimize assets where possible.

---

- Twitter/X card metadata

Use Infectech's official branding and visual identity for social sharing images.

# 12. Internal Linking Strategy

Create a logical internal linking structure.

For example:

- Service pages should link to relevant projects and products.
- Portfolio projects should link to the services used.
- Product pages should link to relevant business solutions.
- Blog or resource content should link to relevant service pages.

Use descriptive anchor text instead of generic phrases like "click here."

The goal is to help both users and search engines understand the relationship between pages.

## Important Instructions

- Preserve Infectech's existing brand identity and website design.
- Prioritize meaningful content and user experience over keyword density.
- Do not use black-hat SEO techniques.
- Do not create duplicate or thin pages purely for ranking.
- Ensure all important pages are crawlable and indexable.
- Follow modern SEO best practices and make the website technically clean, fast, mobile-friendly, and easy for search engines to understand.

The final result should position Infectech as a professional technology company that helps businesses build modern websites, custom software, AI-powered tools, and scalable digital solutions.
